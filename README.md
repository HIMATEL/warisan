# Warisan Akademik HIMATEL Polban

Kumpulan materi, catatan kuliah, tugas, dan modul praktikum yang diarsipkan sebagai bekal akademik dari generasi ke generasi untuk anggota HIMATEL.

Dikelola oleh **Departemen IPTEK HIMATEL Politeknik Negeri Bandung**.

---

## Struktur Repositori

- **`D3/`**: D3 Teknik Telekomunikasi (Semester 1 s.d. 5)
- **`D4/`**: D4 Teknik Telekomunikasi (Semester 1 s.d. 6)

Setiap semester dikelompokkan berdasarkan nama mata kuliah resmi kurikulum Teknik Telekomunikasi Polban.
