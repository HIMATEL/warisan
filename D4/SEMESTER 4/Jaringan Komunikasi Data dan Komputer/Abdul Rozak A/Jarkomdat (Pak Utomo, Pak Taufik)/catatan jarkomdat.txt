### PENGENALAN MODE ###
ada 3 mode dalam perangkat CISCO
1. "switch>" = user mode
2. "switch#" = privilage mode (mode enable)
3. "switch(config) = configure mode

dari user mode ke privilage mode, gunakan:
switch> enable
switch#

dari privilage mode ke configure mode, gunakan:
switch# configure terminal
switch(config)#

ada sistem hirarki:
user mode -> privilage mode -> configure mode

kalau mau mundur, gunakan command "exit"
=========================================
### PENGENALAN ERROR ###
Ada 2 jenis error:
1. pada mode configure:
-----------------------------------------
Switch(config)#misalvtp
                ^
% Invalid input detected at '^' marker.
-----------------------------------------
pada contoh 1, akan ada marked yang menunjukan lokasi error

2. pada mode user dan privilage
-----------------------------------------
Switch#nono
Translating "nono"...domain server (255.255.255.255)
% Unknown command or computer name, or unable to find computer address
-----------------------------------------
pada contoh 2, perangkat akan melalukan name lookup ke server untuk mencari command tsb.

solusi untuk error contoh 2:
1) intrupt command dengan tekan:
"ctrl"+"shift"+6"

2) matikan fungsi lookup:
switch(config)#no ip domain-lookup

7. Set Interface Logic (minggu depan)
- pada tahap ini, kalau kita melihat di command "show vlan brief", kita akan melihat ada 3 buah vlan, yakni vlan 1, vlan 10 & vlan 20
- tapi kalau kita mencek di command "show ip interface brief", kita hanya melihat interface vlan 1 saja, tidak ada interface vlan 10 & vlan 20

Tujuan pada tahap 7 ini:
1. Kita akan membuat interface vlan 10 & vlan 20
2. kedua interface tersebut akan kita gunakan untuk pengalamatan ip address

"kenapa alamat ny tidak di interface fisik saja ? seperti di fastethernet 0/1, dst..?"
jawabannya: karena interface fisik SWITCH, merupakan interface layer 2. pada layer 2 tidak ada konsep IP address. sehingga pada interface fisik SWITCH tidak dapat di assign IP ADDRESS. 

karena IP ADDRESS merupakan konsep layer 3, 
dan SWITCH adalah perangkat layer 2 
==> pada interface SWITCH tidak akan pernah bisa di assign IP Address, kecuali SWITCH LAYER 3 (MULTI LAYER SWITCH)

9. Set line Virtual (SSH)

- SSH adalah fitur remote yang menggunakan keamanan enkripsi RSA
- Syarat untuk membuat SSH, harus terlebih dahulu membuat RSA
- Syarat untuk membuat RSA, harus membuat HOSTNAME dan DOMAIN NAME

a. kita akan mengconfigurasi RSA terlebih dahulu:
1. membuat HOSTNAME:168
(config)# hostname <nama hostname>

2. membuat DOMAIN NAME:
(config)# ip domain name <nama domain>

(config)# hostname SW_1
(config)# ip domain name cisco.com

selanjutnya membuat RSA:
(config)# crypto key generate rsa 
enter dan akan ditanya modulus;
modulus [512] : bisa diisi: 512 atau 1024 2048

Pada metode Router on Stick kita akan menggunakan interface logic
yakni subinterface dari inteface G0/0, 

Konfigurasi Router on Stick
a. pada Router:
- masuk ke interface fisik arah SWITCH
- hidupkan interface fisik
- masuk ke interface logic (subinterface)
- set encapsulation 802.1Q dan VLAN
- set IP Address

1. pertama kita menyalakan terlebih dahulu interface fisik G0/0
(config)# inteface g0/0
(config-if)# no shutdown

2. kita konfigurasi ke interface logic (subinterface)
vlan 10:
(config)# interface g0/0.10                           => masuk subinteface g0/0.10
(config-subif)# encapsulation dot1Q 10                => set encapsulation 802.1Q VLAN 10
(config-subif)# ip address 192.168.10.1 255.255.255.0 => set IP Gateway

vlan 20:
(config)# interface g0/0.20            
(config-subif)# encapsulation dot1Q 20 
(config-subif)# ip address 192.168.20.1 255.255.255.0 

b pada Switch:
- masuk ke interface fisik arah ROUTER
- set interface ke mode Trunk
- set interface Trunk untuk semua VLAN
 
 (config)# interface g0/1                        => akses interface arah ROUTER
 (config-if)# switchport mode trunk              => set interface ke mode TRUNK
 (config-if)# switchport trunk allowed vlan all  => set TRUNK untuk semua VLAN
 
 mode access ==> hanya melewatkan 1 vlan
 mode trunk  ==> melewatkan banyak vlan

KONFIGURASI PADA PC:
- MASUK KE PC 0, 1 dan 2 (VLAN 10)
- MASUK KE DESKTOP -> IP CONFIGURATION -> SET IP DEFAULT GATEWAY (192.168.10.1)
- MASUK KE PC 3, 4 dan 5 (VLAN 20)
- MASUK KE DESKTOP -> IP CONFIGURATION -> SET IP DEFAULT GATEWAY (192.168.20.1)

VERIFIKASI:

- PC DI VLAN 10 (PC 0,1,& 2) HARUS BISA KOMUNIKASI KE PC DI VLAN 20 (PC 3,4,&5)

=====================================
Etherchannel/BundleEther/EtherBundle
=====================================
Fungsi ny menggabungkan beberapa link interface menjadi 1 interface logic

Tipe Etherchannel:
LACP : Open Standar
     : active - pasif
     : active - active
     
PAGP : Cisco
     : desirable - auto
     : desirable - desirable 

aktif (lacp) dan desirable (pagp) => melakukan
transmit negosiasi untuk menjadi etherchannel

pasif (lacp) dan auto (pagp) => tidak melakukan tranmit, melainkan menunggu negosiasi

Konfigurasi:
SW_VL30:
(config)# interface range fa0/13-14
(config-if-range)# channel-group 1 mode active

(config)# interface port-channel 1
(config-if)# switchport mode trunk
(config-if)# switchport trunk allowed vlan all

CORE_SW (MLS):
(config)# interface range fa0/13-14
(config-if-range)# channel-group 1 mode active

(config)# interface port-channel 1
(config-if)# switchport mode trunk
(config-if)# switchport trunk allowed vlan all

(config)# interface range fa0/15-16
(config-if-range)# channel-group 2 mode active

(config)# interface port-channel 2
(config-if)# switchport mode trunk
(config-if)# switchport trunk allowed vlan all

=====================================
VTP : VLAN TRUNKING PROTOCOL
=====================================
FUNGSI: Untuk melakukan konfigurasi VLAN dalam satu perangkat saja , dimana nanti database vlan akan di distribusi ke switch lain

VTP Mode:
1. Server => sumber vlan, dia mengirimkan informasi vlan ke switch lain (aktif)
2. Client => menerima informasi vlan dari Server (pasif)
3. Transparent => independent dari Server, hanya forwarding informasi

Konfigurasi:
Core_SW (MLS):
(config)# vtp domain cisco.com
(config)# vtp password cisco
(config)# vtp mode server

SW_VL30: 
(config)# vtp domain cisco.com
(config)# vtp password cisco
(config)# vtp mode client

SW_VL40:
(config)# vtp domain cisco.com
(config)# vtp password cisco
(config)# vtp mode client

Verifikasi: #show vtp status

(config)#vlan 30
(config-vlan)#name KARYAWAN_VL30
(config)#vlan 40
(config-vlan)#name KARYAWAN_VL40
